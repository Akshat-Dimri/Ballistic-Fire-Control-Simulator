Ballistic Equation Solution Simulator

Welcome! This application presents an interactive proof-of-concept dashboard for computing non-linear fire control ballistic solutions.

Key Capabilities:
• Dynamic Degree Mode Toggle: Switch between 3-Term (Crucial), 5-Term (Tactical), and 8-Term (Complete) calculations.
• PySR Symbolic Regression: Exact trajectory drop curve-fits and environmental perturbation corrections.
• Fully Rendered LaTeX: All correction formulas rendered via KaTeX directly inside term cards and the live formula bar.
